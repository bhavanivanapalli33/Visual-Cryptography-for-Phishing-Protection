# Results

This folder contains the output files generated by the visual cryptography process in the project "Enhancing Online Security Using Visual Cryptography".
These include the cryptographic shares and encrypted/decrypted images.

### Contents:
- Shares: Individual cryptographic shares.
- Encrypted Images: Images after encryption.
- Decrypted Images: Result after combining shares.

These results demonstrate the effectiveness of the visual cryptography technique in enhancing online security.
